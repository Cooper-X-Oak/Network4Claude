# Network4Claude

为 Claude 20x 订阅打造的纯净、稳定网络环境搭建指南。

## 项目背景

使用 Claude Pro/Team 等高级订阅时，网络质量直接影响使用体验：
- IP 纯净度影响账号稳定性
- 网络稳定性影响长对话体验
- 共享 IP 容易触发风控

本项目记录从需求分析、方案选择到实际搭建的完整过程。

## 核心目标

- ✅ **纯净度 < 30**：避免 IP 被标记
- ✅ **人数 < 100**：独享或小范围共享
- ✅ **稳定可靠**：长期使用不中断
- ✅ **成本可控**：性价比优于商业服务

## 方案选择

**最终方案**：搬瓦工 CN2 GIA VPS 自建
- 成本：$50/年（约 350 元/年）
- 流量：500GB-1TB/月
- 支持：2-3 人共享使用
- 优势：完全可控的 IP 纯净度

详见：[决策过程](docs/01-decision.md)
