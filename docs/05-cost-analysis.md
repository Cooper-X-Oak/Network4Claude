## 一、Claude 官方订阅

- 5-10 倍 Pro 的使用量
- 更高的并发限制
- 企业级支持

**年成本**：
- 订阅费：$1,200-2,400/年 ≈ ¥8,400-16,800/年

**额度**：
- 类似 Pro，但支持团队协作
- 共享工作空间
- 管理控制台

**年成本**：
- 单人：$360/年 ≈ ¥2,520/年

## 二、中转站方案

### 什么是中转站

第三方 API 代理服务，通过转发请求访问 Claude API。

### 成本结构

**按 Token 计费**（市场价格，2026）：
- Input Token：¥0.01-0.03 / 1K tokens
- Output Token：¥0.05-0.15 / 1K tokens

### 使用量估算

**假设场景**：日常使用 Claude
- 每天对话：20 次
- 每次对话：平均 500 tokens input + 1000 tokens output
- 每月对话：600 次

**月成本计算**：
```
Input:  600 × 500 × 0.02 / 1000 = ¥6
Output: 600 × 1000 × 0.10 / 1000 = ¥60
总计：¥66/月
```

### 优劣分析

**优势**：
- ✅ 按量付费，轻度使用便宜
- ✅ 无需订阅
- ✅ 灵活切换模型

**劣势**：
- ❌ 重度使用成本高
- ❌ 服务稳定性不保证
- ❌ 可能随时跑路
- ❌ 数据隐私风险
- ❌ 可能被限流

### 方案 C：官方 Max + 纯净线路

**月成本**：

**年成本**：¥8,748-17,148

## 四、单位成本分析

### 按对话次数计算

**假设**：Claude Pro 每月 300 条消息 × 30 天 = 9,000 条

| 方案 | 月成本 | 月消息数 | 单条成本 |
|------|--------|----------|----------|
| 中转站（轻度） | ¥66 | 600 | ¥0.11 |
| 中转站（重度） | ¥200+ | 2,000+ | ¥0.10+ |
| Pro + 普通网络 | ¥157 | 9,000 | ¥0.017 |
| Pro + 纯净线路 | ¥169 | 9,000 | ¥0.019 |
| Max + 纯净线路 | ¥729-1,429 | 45,000-90,000 | ¥0.016-0.032 |

### 按使用强度分类

**轻度使用**（< 1,000 条/月）：
- 推荐：中转站
- 单位成本：¥0.10-0.15/条

**中度使用**（1,000-5,000 条/月）：
- 推荐：Pro + 纯净线路
- 单位成本：¥0.019/条

**重度使用**（> 5,000 条/月）：
- 推荐：Pro + 纯净线路（性价比最高）
- 或 Max + 纯净线路（需要更高额度）
- 单位成本：¥0.016-0.032/条
