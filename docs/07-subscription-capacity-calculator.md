## 四、各档位容量测算

### 4.1 容量计算公式

给定 API 预算 B，按用户使用比例分配：

```
输入 Token (I) = B / (Pi + Ro × Po + Rc × Pc)
输出 Token (O) = I × Ro
缓存 Token (C) = I × Rc
```

其中：
- Pi = $3/1M (输入单价)
- Po = $15/1M (输出单价)
- Pc = $0.3/1M (缓存单价)
- Ro = 0.0475 (输出/输入比例)
- Rc = 13.36 (缓存/输入比例)

### 4.2 分母计算

```
分母 = Pi + Ro × Po + Rc × Pc
     = 3 + 0.0475 × 15 + 13.36 × 0.3
     = 3 + 0.7125 + 4.008
     = 7.7205 USD/1M tokens
```
