# 决策过程：为什么选择自建

## 需求背景

### 使用场景
- **主要用途**：Claude 20x 订阅（Pro/Team）
- **月流量**：约 100GB
- **用户数量**：2-3 人共享
- **核心要求**：
  - 纯净度 < 30
  - 人数 < 100
  - 长期稳定

### Claude 的特殊要求

**IP 风控严格**：
- 共享 IP 容易触发人机验证
- 频繁切换 IP 可能导致账号异常
- 数据中心 IP 可能被限制

**稳定性要求高**：
- AI 对话中断会丢失上下文
- 长对话（Claude Code 等）需要持续连接
- 网络抖动严重影响体验

**纯净度要求**：
- 被标记的 IP 可能无法注册/登录
- 滥用 IP 会被限流或封禁

## 方案对比

### 方案一：购买商业服务

**成本**：100 元/半年

**优势**：
- 价格较低
- 零技术门槛
- 通常有多节点可选
- 有客服支持

**劣势**：
- ❌ 无法保证纯净度持续达标
- ❌ 人数可能随时增加
- ❌ 跑路风险
- ❌ 被封后需要重新寻找
- ❌ 可能有流量限制/限速

### 方案二：自建 VPS

**成本**：175-210 元/半年

**优势**：
- ✅ 完全可控的 IP 纯净度
- ✅ 独享带宽，不限速
- ✅ 流量富余（500GB-1TB/月）
- ✅ 长期稳定，不用频繁换服务商
- ✅ 可分享给家人/朋友

**劣势**：
- 需要一定技术能力（但有教程）
- 首次搭建需要 1-2 小时

## 成本分析

### 直接成本对比

| 项目 | 商业服务 | 自建 VPS | 差额 |
|------|----------|----------|------|
| 半年成本 | 100 元 | 175 元 | +75 元 |
| 月均成本 | 17 元 | 29 元 | +12 元 |
| 月流量 | 100-200GB | 500-1TB | 多 3-5 倍 |

### 隐性成本

**商业服务**：
- 寻找新服务商的时间成本
- 频繁切换导致的配置成本
- IP 被污染影响使用的机会成本

**自建 VPS**：
- 首次搭建：1-2 小时
- 后续维护：几乎为零

### 与 Claude 订阅的对比

- Claude 20x 订阅：~$20/月（140 元/月）
- 网络成本（自建）：29 元/月
- **网络成本只占订阅费的 20%**

**结论**：既然愿意为 Claude 付费，多花 12 元/月换取稳定体验是值得的。

## 最终决策

**选择：搬瓦工 CN2 GIA $50/年**

**理由**：
1. **针对中国优化**：CN2 GIA 线路，速度快
2. **IP 质量好**：相对干净，适合 Claude 使用
3. **流量充足**：500GB/月，支持 2-3 人使用
4. **性价比高**：$50/年 ÷ 3 人 = 117 元/年/人

**风险控制**：
- 建议配置备用方案（便宜服务商作为应急）
- 定期检查 IP 纯净度
- 规范使用，避免滥用
