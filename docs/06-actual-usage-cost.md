## 六、成本优化建议

### 1. 智能路由策略

```

  - 架构设计
  - 复杂推理
  - 关键决策
```

**节省**：相比纯 Sonnet 节省 ¥59,465 - ¥72,443 = -¥12,978

```

  Cache:  10,290M × $0.3 = $3,087
  小计：$5,946

Haiku 部分（30%）：
```

**优化方向**：
- 缓存成本占比：$4,410 / $8,495 = 52%
- 如果能减少 50% 缓存使用：节省 ¥15,450/月

**方法**：
- 优化 prompt 结构
- 减少重复上下文

### 3. 批量处理

- 使用 Batch API（如果可用）
