# Archived Index Experiments

These files are earlier landing-page experiments for Network4Claude. They are kept for historical reference only and are not part of the active product surface.

Reasons for archiving (2026-05-12):

- **3 parallel attempts** with no convergence. Each came from a different model session and none became the chosen implementation.
- **Pre-current-entry prototypes**. They predate the active root [`index.html`](../../../index.html) and each carried its own persona-picking logic instead of consuming the shared data files.
- **Rejected visual direction**. The pixel-art direction in `index-clean.html` was explicitly rejected and replaced by the brief in [`docs/design-brief-pixel-cards.md`](../../../docs/design-brief-pixel-cards.md).

Current active entry: root [`index.html`](../../../index.html).

Legacy note: some archived files in this directory still reference the removed `calculator.html`. Those references are historical only and must not be treated as active routing or product guidance.

Do not import code from this directory.
